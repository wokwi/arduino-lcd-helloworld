# Arduino + LCD1602 example for Wokwi

This is a simple example of using an LCD1602 display with an Arduino Uno in Wokwi for VS Code.

## Build

You can compile this project using the [official Arduino CLI](https://arduino.github.io/arduino-cli/installation/):

```bash
arduino-cli compile -e
```

## Simulate

To simulate this project, install [Wokwi for VS Code](https://marketplace.visualstudio.com/items?itemName=wokwi.wokwi-vscode). Open the project directory in Visual Studio Code, press **F1** and select "Wokwi: Start Simulator".
